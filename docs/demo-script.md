# Demo 劇本（對齊設計書 §23）

## 事前準備
1. `uvicorn app.main:app --reload`（backend/ 內）與 `npm run dev`（frontend/ 內）
2. 瀏覽器開 http://localhost:5173，以示範帳號「Vincent」登入

## Demo 1：語音建立案件
1. 首頁點「點擊並說出需求」進入對話頁
2. 按麥克風說：「我要預約明天下午洗兩台冷氣，地址是嘉義縣民雄鄉文隆村7鄰33號」
3. AI 只補問電話 → 說出「0912-345-678」
4. AI 顯示確認摘要 → 說「確認」
5. AI 回覆案件編號；回首頁可見「冷氣清潔／等待廠商確認」

## Demo 2：案件追蹤
1. 點擊剛建立的案件卡片
2. 展示：狀態徽章、表單資料、完整對話紀錄

## Demo 3：個人化長期記憶
1. 回首頁再建立新需求：「我想洗洗衣機」
2. 依序回答數量、類型、日期後，AI 主動詢問：
   - 「要安排在您偏好的下午時段嗎？」
   - 「要使用您上次的服務地址嗎？」
   - 「聯絡電話要使用上次留的⋯嗎？」
3. 全部回「好」，展示零重複輸入的體驗

## Demo 3.5：AI 代操表單（「我幫你填」）
1. 首頁點「冷氣清洗」服務卡片，進入服務表單頁（整張表單是空的）
2. 點右下角「AI 管家」，直接說（或輸入）：
   「幫我填，兩台壁掛式冷氣，不用抗菌膜，禮拜三下午兩點半」
3. 面板自動收起來，表單開始**逐格被填**：每一格先高亮、再寫入值，填完標上「AI 已填」；
   上方狀態列顯示「AI 管家代填中 5/7」
4. 地址與電話直接沿用上次資料，欄位旁標註「沿用你上次填的資料」——不必再問一次
5. 使用者只要檢查畫面、按「送出服務需求」即可；想改哪一格再跟管家說
   「服務時間改成下午三點」，那一格會再被高亮改掉，其他格不動
6. 對照組：在同一頁問「這頁可以做什麼」，管家仍然只做頁面導覽問答（不會亂動表單）

> 也可以從首頁直接說「幫我填洗衣機清洗的表單」：管家會先把你帶到那張表單頁，再開始代填。

## Demo 4：多使用者隔離
1. 登出，改以「美惠」登入
2. 首頁案件列表為空、AI 不會帶出 Vincent 的地址與偏好

## Demo 5：廠商後台
1. 另開分頁進 http://localhost:5173/vendor/login （住戶端登入狀態不受影響）
2. 點 Demo 帳號「潔家家事服務」一鍵登入
3.「待確認諮詢單」分頁出現 Demo 1 建立的冷氣清洗案件，含客戶、日期時段與地址
   （地址只到行政區，例如「台北市信義區…」）
4. 點開案件明細，展示服務內容；「聯絡資訊」區塊標示「已加密保護」，電話顯示
   `0912***678`
5. 按「顯示完整聯絡資訊」→ 換成完整電話與地址，下方「存取紀錄」立刻多一筆
   「潔家家事服務 檢視了 聯絡電話、服務地址」（解密留痕，Milestone 15）
6. 按「接下這張單」→ 狀態變成「已確認」，回清單已移到「已接訂單」分頁；
   切回住戶端分頁重新整理，同一張單也同步顯示「已確認」
7. 重複操作示範：接單前先開兩個案件明細分頁，兩邊都按接單——第二個會顯示
   「案件目前是『已確認』，無法接單。」並自動更新成現況（狀態機 + 樂觀鎖）
8. 切到「安心水電工程行」帳號登入，同一張單看不到 —— 廠商只看得到自家
   `service_vendor_id` 的案件
